## Codebase Patterns
<!-- Patterns discovered during development -->
- Next.js 14 App Router: use src/app/ structure
- shadcn/ui: components go in src/components/ui/
- Scanner services: each in src/lib/scanner/[type].ts
- All scanners read from ~/.claude/ directory
- Use gray-matter for YAML frontmatter parsing
- Use date-fns for relative time formatting
- Tailwind v4: uses CSS-based config, no tailwind.config.ts file
- Path aliases: tsconfig.json needs baseUrl and paths for @/* imports

## Key Files
- ~/.claude/commands/ - Global slash commands (*.md)
- ~/.claude/agents/ - Custom agents (*.md)
- ~/.claude/plugins/installed_plugins.json - Plugin list
- ~/.claude/settings.json - Enabled plugins
- ~/.claude/hooks/ - Automation scripts
- ~/.claude/skills/ - Complex skills (folders)

## Tech Stack
- Next.js 14+ with App Router
- TypeScript
- Tailwind CSS
- shadcn/ui components
- Node.js fs for file scanning
